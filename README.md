# Luigi Paciello – personal website

Plain static HTML, served by GitHub Pages. No build step.

- `index.html` – home / bio
- `research.html` – papers (each paper is one `<li>` block; copy one to add a paper)
- `teaching.html` – courses
- `style.css` – all styling
- `photo.jpg` – profile photo

CV: source `cv/paciello_cv.tex` → compile with pdflatex → copy PDF to `paciello_cv.pdf`. Papers: `papers/`.
